# مِعيار | MEYAR

**بوابتك لإتقان المحاسبة** — منصة تعليمية عربية مجانية في نسختها الأولى.

## محتويات الموقع
- `index.html`: الصفحة الرئيسية.
- `basics.html`: مسار أساسيات المحاسبة.
- `lesson-1.html` إلى `lesson-5.html`: خمسة دروس مستقلة، وكل درس مقسم إلى ثلاثة أجزاء مع التنقل والتطبيق.
- `dictionary.html`: قاموس محاسبي إنجليزي قابل للبحث.
- `quiz.html`: اختبار تأسيسي بتصحيح فوري.
- `simulation.html`: محاكاة مبسطة لعمليات محاسبية شائعة.
- `templates.html` ومجلد `templates/`: قوالب CSV قابلة للتنزيل والفتح في Excel.
- `interviews.html`: أسئلة مقابلات العمل للمحاسبين مع إجابات وتدريب.
- `style.css`: تنسيق وهوية الموقع.
- `progress.js`: حفظ تقدم الدروس وأفضل نتيجة للاختبار محلياً في المتصفح.

## التشغيل
افتح `index.html` في متصفح حديث. الموقع ثابت ولا يحتاج إلى تثبيت أو خادم أو قاعدة بيانات، ويعمل دون اتصال بالإنترنت بعد تنزيل الملفات.

## ملاحظات مهمة
- المحتوى تعليمي تأسيسي، ويجب مراجعة السياسات المحاسبية والأنظمة المحلية والمعايير المطبقة قبل استخدام أي نموذج في عمل فعلي.
- محاكاة القيود مبسطة، وقد تختلف المعالجة بحسب نظام الجرد والسياسات المحاسبية وطبيعة العملية.
- لا توجد حاليًا حسابات مستخدمين أو لوحة تحكم أو شهادات أو حفظ سحابي للتقدم. حفظ الإنجاز الحالي محلي على نفس الجهاز والمتصفح فقط، وقد يختفي عند مسح بيانات المتصفح أو استخدام جهاز آخر.
- المشروع غير منشور على الإنترنت بعد؛ رفع الملفات إلى GitHub يحفظ نسخة الكود، ولا ينشر الموقع تلقائيًا.

## الهوية
الألوان الأساسية: كحلي داكن وذهبي وأبيض. اللغة: العربية من اليمين إلى اليسار.
